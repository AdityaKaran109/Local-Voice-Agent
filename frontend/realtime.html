2 · Voice-to-voice (speech-native) models

A single model hears audio and speaks audio directly, with no separate STT and TTS. Latency drops to a few hundred ms and tone carries through, but you lose control over each stage and it's harder to make tool-heavy work reliable. The browser connects straight to the model; this server only mints a short-lived token. Gemini Live is the same model family as Vocal Bridge's "Gemini" agent style.
