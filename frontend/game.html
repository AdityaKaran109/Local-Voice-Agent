3 · Voice in your app

Say "put me in the center" or "top right", or just click. Voice and mouse input go through the same play() function on the server and both land in the conversation history, so the agent always knows the true board state.

You are X · the agent is O

How it works

  • Voice → STT → LLM calls make_move(square) → server updates the board and picks the agent's reply move.
  • Click → action message → the same play() → a note like "[clicked square 5]" is added to the chat history.
  • The server pushes the board to the UI after every change, so both channels stay in sync.
