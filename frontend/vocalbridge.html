Vocal Bridge — the course's platform

The course builds every lesson on Vocal Bridge: a real-time foreground voice agent with a reasoning background agent. Your agent's prompt, voice style (Chatty, Focused, Gemini, Ultravox) and client actions live in the Vocal Bridge dashboard; this page connects to it with the official SDK. Your API key stays on the local server.

Same tic-tac-toe as lesson 3, wired through Vocal Bridge client actions. The agent sends make_move {square} when you say where to go; clicks and the agent's replies go back as board_update, so voice and mouse share one state.

Client actions to add to your agent

Add these in the dashboard, or with vb config set --client-actions-file data/vocalbridge/client_actions.json (run vb docs to confirm the exact schema for your account). Suggested prompt line: "You are playing tic-tac-toe; the user is X. When they say where to move call make_move with square 1-9 (1 top-left … 9 bottom-right). Narrate board_update events in one short sentence."

In AI Agent mode, the Vocal Bridge voice agent delegates domain questions to your agent and speaks the answer, which is the lesson-4 pattern. Here the delegated questions go to the local Velo Bikes RAG agent. Enable AI Agent mode on your Vocal Bridge agent first, e.g. vb config set --ai-agent-enabled true --ai-agent-description "Velo Bikes customer support".
